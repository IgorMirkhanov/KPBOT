# Техническое задание: Telegram-бот "Конструктор КП" с генерацией PDF/Word

## 1. Общее описание проекта
Разработка Telegram-бота на Python, который работает как пошаговый интерактивный конструктор Коммерческих Предложений (КП). Бот собирает данные от менеджера через FSM (шаблоны, имя клиента, цены, условия), подставляет их в готовый шаблон и компилирует финальный документ в формате PDF и DOCX для отправки клиенту.

## 2. Технологический стек
- **Язык:** Python 3.11+
- **Фреймворк:** aiogram 3.x (управление сценарием через FSM)
- **Шаблонизатор:** Jinja2 (для динамической подстановки данных в макет)
- **Генерация PDF:** WeasyPrint (компиляция HTML+CSS в документ печатного качества)
- **Генерация Word:** python-docx (альтернативный вариант выгрузки в .docx)

## 3. Сценарий работы (FSM States)
1. `waiting_for_service_type` (Инлайн-кнопки) — Выбор категории/пакета услуг.
2. `waiting_for_company_name` (Текстовый ввод) — Название компании-получателя.
3. `waiting_for_price` (Текстовый ввод) — Стоимость со встроенной валидацией на числа.
4. `waiting_for_payment_terms` (Инлайн-кнопки) — Выбор условий оплаты (Предоплата 50%, 100% и т.д.).
5. `waiting_for_extra_conditions` (Текст/Кнопка) — Особые условия (с инлайн-кнопкой "Пропустить").
6. `waiting_for_confirmation` (Инлайн-кнопки) — Вывод текстового превью всех введенных данных и кнопки: `[ Сгенерировать КП ]` и `[ Сбросить ]`.

## 4. Требования к генерации документов (Модуль `document_generator.py`)
- **Входные данные:** Словарь (dict) из FSM контекста.
- **Логика генерации PDF:** Применить Jinja2 к HTML-шаблону `template.html`, передать полученный HTML в WeasyPrint для сборки `kp_output.pdf`.
- **Логика генерации Word (опционально):** Использование python-docx для заполнения `.docx` файла.
- **Выходные данные:** Бот отправляет сгенерированный документ в чат методом `FSInputFile`.
